# 下拉组件统一设计 · 2026-10-28

用户截图中的选择工具展开为 macOS 默认深色菜单，与当前 CAE 界面不一致。本次将所有单选 select 的关闭与展开状态统一设计。

## 覆盖范围

项目/模型、部件/分析步/任务上下文、目录树/消息/AI 停靠位置、模型树方案、Node/Element 选择、节点集合只读类型、分析步参数、设计域方向、载荷配置等单选下拉共用 `src/styles/select.css`，尺寸和展开层参数集中在 `src/styles/tokens.css`。未添加组件库。

- 白色展开面板、蓝灰细边与轻阴影；圆角 4px。
- 菜单统一 30px 行高、12px 字号；项目/上下文、面板标题、表单按区域保持既有密度。
- 选中项浅蓝底、蓝色文字和右侧勾选；悬停/键盘焦点有可见反馈。
- 勾选使用统一 14px SVG 遮罩，1.7px 线宽、圆润端点；右侧居中，替代系统字体对号。
- 禁用项灰色，保留原因文案；Node/Element 约束保持。
- 箭头统一，展开时反向；焦点边框、展开边框一致。

这些数值为原型设计决策，不声称从截图精确提取。

## 实现与兼容范围

保留原生 select/option 语义、受控值和键盘选择。支持 `appearance: base-select` 的浏览器使用可设计的 picker，展开面板进入浏览器顶层，可在弹窗及滚动面板内呈现。

本机 Chrome 156 已确认支持；不支持该能力的引擎使用相同关闭态样式并退回原生展开菜单。未声称全部浏览器或 Windows 桌面宿主均呈现相同效果。

依据：[Chrome 官方可自定义 select 文档](https://developer.chrome.com/blog/a-customizable-select)。

## 验证

证据目录：`../../outputs/prototype-review-20261028/dropdown-design/`。包括展开截图及浏览器检查。重点检查鼠标展开、键盘跳过禁用项、Esc 关闭并恢复焦点、弹窗菜单取消不误关弹窗、125% CSS 缩放。当前验证结论见该目录 `verification.md`。

类型检查、Lint、构建及 Chromium 全量 37 项浏览器检查通过，页面异常、控制台错误与资源错误均为 0。之后仅替换勾选图形，再次构建通过，并在实际展开菜单中核对选中项显示 SVG、未选中项隐藏勾选；未重新执行全量回归。构建仍有约 900 kB 主脚本体积提醒。上述截图与原始检查记录保留在本地忽略的 outputs 目录中。
