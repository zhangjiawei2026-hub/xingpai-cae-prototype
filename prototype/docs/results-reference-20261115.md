# SiPESC.PRE 工作台结果模块 · 2026-11-15

在仓库的 `prototype/` 运行 `npm ci` 和 `npm run dev`，在工作台顶部选择「结果」。结果 Ribbon 和示意网格在原工作台内显示，原有模型树、信息窗口、AI 对话、停靠布局及模块样式可继续使用。通过「网格」返回原模型视图区。原型内置示意数据，刷新或恢复演示会清除结果设置。

## 客户意见与自审对应

| 项目 | 本轮处理 |
| --- | --- |
| 工作台入口 | 移除独立参考页，在 `Workspace` 模块状态中加入「求解」「结果」，保留原有「优化」与既有建模流程。求解入口展示待接入命令 |
| 布局 | 「结果」模式展示文件、编辑、视图、工具、帮助和六组结果常用工具。文件读写、工程级编辑、方向及测量入口为禁用示意；显示方式、图例、视图复位和面板显隐使用当前工作台行为 |
| 数据与联动 | 结果 Ribbon 保留 11 组顺序。恢复 R07 结果字段及分析步。关云图时禁用分量，关变形时清除叠加原形，常规模式显示静态振型或已保存结果帧 |
| 倍数与剖切 | 手动倍数在 0 与 20 之间（含 20）连续改变示意几何。超出范围时保留上次有效输入并提示。上限只服务于示意网格可读性。放大后仍可剖切、反向与复位 |
| 分屏与探针 | 各窗共享同一色阶与几何，探针独立。清除最后一个探针后焦点移到可用的探针按钮 |
| 图标 | 结果专用图标扩展原工作台的等轴测 CAE SVG 体系。实际 Ribbon 和状态对照使用同源组件。图标清单见 [icon-manifest.md](icon-manifest.md) |
| 待定义命令 | 导出、报告和自定义运算打开入口说明。示意几何、极值、探针和时序使用会话内演示数据 |

客户 R07 提供布局、字段和状态依据，浏览器运行取证来自 GitHub 工作台原型。完整工程求解、真实结果数据与导出仍待接入。

## 验证

以实际工作台首页进入「结果」，使用 Chromium 在 1363 × 936 CSS 像素下复验。检查包括同页进入、原有面板、十一组 Ribbon、六组常用工具、客户字段、控件依赖、4 倍/10 倍几何差异、越界校验、分屏的 48 个网格面逐面一致、探针键盘焦点、动画、剖切与返回网格模块。结果视图使用 SVG，在云端浏览器可直接核对。现有 WebGL 模型的真实拾取与整套桌面回归不在本次复检范围。
