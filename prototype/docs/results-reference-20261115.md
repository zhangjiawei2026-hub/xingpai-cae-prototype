# SiPESC.PRE 结果模块参考 · 2026-11-15

从现有工作台的菜单行选择「结果模块参考」，原型会在新标签页打开。也可单独用浏览器打开 `public/reference/results-reference.html`。原型安装在现有工程中，使用独立的会话状态和内联 SVG。

## 参考依据

以客户菜单工具栏 R07 与结果模块截图为依据。保留其 11 组工具的呈现顺序。独立参考页集中演示结果操作，模块位置条用于说明结果的入口位置。全局菜单、建模命令、求解和常用工具栏使用原工作台流程另行评审。

## 功能对照

| 分组 | 可评审的内容 |
| --- | --- |
| 结果数据 | 模态、结构和温度三种示例，分析步、振型或帧、变量与分量联动 |
| 显示模式 | 常规线性与简谐互斥，温度示例禁用简谐 |
| 云图 | 显隐独立于变形，变量与分量影响示意色阶 |
| 变形 | 开关、自动与手动倍数、叠加原形和恢复原形 |
| 结果剖切 | 切面、偏移、反向和复位，通过二维投影示意 |
| 图例与范围 | 图例显隐、自动或手动范围，手动范围影响示意色阶 |
| 动画 | 上一帧或振型、下一帧或振型、播放、暂停、停止与相位 |
| 查找关键位置 | 鼠标或键盘添加探针，单点移除，清除当前或全部，极大值与极小值独立显隐 |
| 导出与报告 | 入口及待确认的格式、字段与模板 |
| 自定义运算 | 入口及待确认的输入、语法与校验 |
| 多窗口对比 | 单窗、左右两窗、上二下一、四窗，活动窗口及各窗探针 |

「图标与状态」收录 22 项 SVG 参考图标，对应默认、禁用及适用的选中态。图标造型和标注仍属评审方案。视图区使用示意网格与示意极值标签。多窗共享结果参数，探针各窗独立。文件读取、真实 CAE 计算、工程结果导出及真实报告生成未接入。
