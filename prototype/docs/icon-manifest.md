# 图标状态清单 · v0.3

首批最终清单尚未提供，以下不是已确认的专业图标交付。专业语义图标集中在 `src/components/CAEIcon.tsx`（样式 `CAEIcon.module.css`，配色 `src/styles/tokens.css` 中的 `--ci-*`），均为本轮原型占位，语义待专业复核。

## 视觉规则（原型设计决策）

- 共用 32×32 viewBox，等轴测风格：高饱和三面明暗（顶面浅、左面中、右面深）+ 半透明同色描边；前立棱与顶面前棱用白色高光表现受光边；网格线为白色线框。
- 分析步改为三根递增圆角柱（同一时间轴上的逐级加载），替代原阶梯折线。
- 质感（参考 Dribbble/Behance 上等轴测图标集的常见做法，未复制具体作品）：统一左上光源，三面使用渐变而非纯色；几何体使用同色系深蓝描边（`--ci-geo-ink`）；顶面前棱内侧加白色高光；20px 及以上为落地物体（部件、网格、节点、种子、装配、材料）加柔和投影；材料球、节点与角标使用径向/纵向渐变。渐变按实例生成，CSS 通过 `--cig-*` 引用，缺失时回退到纯色 token。
- 色彩分类：几何/网格为蓝，材料/截面为紫，分析步/优化历程为青绿，载荷/约束为橙红，选中对象（节点、种子、设计域）为琥珀。
- 光学尺寸：描边按屏幕像素保持清晰（大图标 1.35px，小图标 1.15px）；小于 20px 时省略细节线。
- 动作角标（右下圆形）：add 新建、edit 编辑、manage 管理、delete 删除（红）、move 平移、rotate 旋转、view 显示/隐藏、assign 指派。角标表达动作，主体表达对象。
- 视口工具条与视图方向面板统一使用 CAEIcon（等轴测、适合窗口与 Ribbon 同图标），不再使用通用线性图标。
- Figma 基线中的待接入命令保留彩色图标，以 aria-disabled 和 title 标记；点击仅说明未接入原因，不执行命令。操作会话锁定时使用原生 disabled。
