## 2026-10-23 审核修复补充

- 恢复多材料/多截面优化分组。激活与类型只保存演示草稿，列表缺少真实数据而禁用，不代表可执行多材料优化。
- 脱模增加方向最大尺寸文字草稿、类型入口与障碍物入口。仅开放 SINGLE 直线字段示意；SPLIT、CYL、SPHER、CRVTHNW 依赖与障碍物对象未确认，禁用。没有新增工程单位、范围和对象数量限制。
- 专业选择条展示单选（逐项累积的显示网格拾取）、框选、几何面/角度关联和集合选择。后四项未接入算法而禁用；已有集合读取仍是独立复制流程。
- 已有集合、分析步、设计域以 ID 回填独立草稿，取消不写入，保存替换原对象，同名排除自身。编辑不改变列表顺序。树双击、右键、F2 与 Ribbon 复用 open 动作；Initial 不支持编辑。
- 模型树方向键只移动焦点或展开/折叠，Enter/空格选择；搜索期间匹配分支自动展开，左键定位父级。每次树渲染校正唯一 Tab 停靠点。
