# AI 对话面板颜色与图标态 · 2026-10-29

只调整 AI 对话面板内部的颜色、图标态和反馈色。停靠位置、面板宽高、上下文栏、正文、快捷问题和草稿区的上下顺序都没有改。

## 颜色怎么读

| 状态 | 颜色 | 出现位置 |
| --- | --- | --- |
| 品牌蓝 | 现有 `--blue` / `--blue-soft` | 模型图标、助手标、快捷问题图标、草稿铅笔；选中的问题整行浅蓝底、蓝描边、箭头转蓝 |
| 警示棕 | 现有 `--selection-ink` / `--selection-bg` | 「AI 服务未连接」图标和文字；草稿写好后的发送图标，以及「发送不可用」说明 |
| 可读蓝灰 | 现有 `--ink-control` | 说明、占位符、未选中箭头、空草稿时的发送图标。不再使用过浅的灰，也不再把禁用按钮整体降到 38% 透明度 |
| 错误红 | 现有 `--error` | 仅清空按钮在可点击时的悬停和按下 |

发送始终禁用，不会发起请求，也没有「正在生成」的转圈。空草稿时发送图标是清晰的蓝灰；写入草稿后，图标、浅底和描边改为警示棕，与「未连接」同一语义，避免被看成可以发送。底部矮面板会藏起说明文字，这时按钮本身的棕色仍然表明发不出去。

入口「AI 对话」打开后使用同一套蓝色按下态，位置仍在上下文栏原处。
