# AI 对话面板颜色与图标态 · 2026-10-29

只调整 AI 对话面板内部的颜色、图标态和反馈色。停靠位置、面板宽高、上下文栏、正文、快捷问题和草稿区的上下顺序都没有改。

## 颜色怎么读

| 状态 | 颜色 | 出现位置 |
| --- | --- | --- |
| 品牌蓝 | 现有 `--blue` / `--blue-soft` | 快捷问题选中后的浅蓝底；助手标使用固定图片 `/assistant-icons/assistant-mark.png` |
| 警示棕 | 现有 `--selection-ink` / `--selection-bg` | 「AI 服务未连接」；草稿写好后，仅「发送不可用」说明改为同色 |
| 可读蓝灰 | 现有 `--ink-control` | 说明、占位符、未选中箭头，以及发送图标（空草稿和已写草稿都保持蓝灰，不改成警示棕） |
| 错误红 | 现有 `--error` | 仅清空按钮在可点击时的悬停和按下 |

发送始终禁用，不会发起请求，也没有「正在生成」的转圈。发送图标保持与工具条禁用控件一致的蓝灰，不单独改成警示棕；写入草稿后，只有「发送不可用」说明使用警示棕。助手图标固定为分析步造型，不再提供方案切换。

入口「AI 对话」打开后使用同一套蓝色按下态，位置仍在上下文栏原处。
