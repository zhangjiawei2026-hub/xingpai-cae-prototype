# AI 对话面板 UI 优化 · 2026-10-29

以当前 CAE 工作台蓝灰色、紧凑控件为基准，将原占位区域拆为模型上下文、助手空态、快捷问题和底部草稿输入区。使用统一 Lucide SVG，焦点边框、清空按钮、禁用发送状态保持一致。短面板压缩介绍；顶部/底部停靠优先展示草稿输入。

快捷问题只填入可编辑草稿，不生成回答。草稿按模型隔离，在当前会话换边、隐藏重开后保留；刷新清空。AI 服务未接入，发送禁用并提供原因，未进行网络请求或模型数据上传。

验证：typecheck、lint、13 项现有状态测试、build 通过；build 保留大于 500kB 包体积提示。Playwright 在本地 Chromium 验证快捷问题、换边、重开、模型切换草稿隔离、发送禁用和清空；查看右侧与底部截图。局部 UI 验证未重跑全量浏览器回归。
