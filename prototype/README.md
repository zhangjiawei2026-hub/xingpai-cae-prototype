# SiPESC.PRE · React 交互原型

2026-10-22 · v0.2。本地桌面工作区原型，用于评审视觉、控件状态和代表性配置流程。

## 本地运行

在本目录执行：

```bash
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

访问 http://127.0.0.1:5173 。需要支持 WebGL 的现代桌面浏览器。建议窗口至少 1280×720；界面最小宽度 1000px，较窄窗口横向滚动。未接入在线字体或远程模型。

```bash
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
npm run preview -- --host 127.0.0.1
```

`test:e2e` 需要本机 Google Chrome，使用生产构建，自行启动并关闭 4173 端口的预览服务。先运行 `build`。检查记录和截图默认写入项目根目录 `outputs/prototype-review-20261022/v0.2-时间戳/`，每次运行创建新目录。可通过 `CAE_ARTIFACT_DIR` 指定独立目录。如端口被占用，先释放该端口。浏览器自动化使用软件 WebGL，不代表硬件 GPU 性能验收。

## 可以体验

- Ribbon 大图标、双排小图标和代表流程入口；模块切换、按模块变化的对象上下文。
- 模型树展开折叠、搜索、右键创建、创建后更新；树宽度可拖动，也可聚焦分隔条后用左右键调整。
- 支架三维模型：拖动旋转、右键平移、滚轮缩放、前/顶/右/等轴测视图、显示边线。
- 节点集合：Node 类型限制、拾取、快捷选择、已有集合复制、确认/取消和会话内创建。
- 分析步：类型选择 → 参数草稿 → 创建，支持返回上一步保留草稿。
- 设计域：单元拾取、基础/最大尺寸/脱模页签、激活与禁用、基准对象拾取。
- Model-Empty 空模型与结果空态，面板显隐、消息日志、焦点约束和 Esc 取消。

## 演示脚本

1. 点击 Ribbon 的“节点集合”，填写名称后点击“拾取节点”。在模型上点击，或使用底部 N001–N008 快捷选择。确认后创建，在树与日志查看新对象。
2. 点击“分析步”，选择当前支持的“静力，通用”，继续到参数页。切换自动/手动并编辑可选字段；返回再继续，检查草稿保留；创建后检查 Step 上下文。
3. 点击“设计域”，拾取演示单元；填写可选尺寸，切换“脱模”并激活，分别选择基准点和第一点，再创建。
4. 重新进入任一流程，检查取消不会提交；切换空模型，检查对象不会跨模型混用。刷新或“文件 → 恢复初始演示”回到初始数据。

## 技术与边界

使用 React 19.3.1、TypeScript 6.0.3、Vite 8.3.5、Three.js 0.186.1；确切依赖及传递依赖以 `package-lock.json` 为准。版本初始化时通过 npm registry 核实，构建工具要求 Node ^20.19 或 >=22.12。React Context + reducer 管理工作区，表单草稿局部管理，Three.js 适配层独立于 React 渲染。

- 数据只存在内存中，不写本地存储、不连接后端；刷新恢复初始状态。
- 支架为程序生成的显示几何，共 1,084 个去重顶点和 2,180 个三角面。这些 ID 不代表真实 FEM 节点/单元；显示拾取不构成工程选择验证。
- 当前 Node 选择通过射线命中三角面后取最近显示顶点；Element 对应显示三角面。不是有限元网格生成器。
- 专业图标是占位 SVG，首批最终图标清单尚未提供；灰色命令未实现。
- 未接入 CAD 导入、真实网格、材料数据库、工程求解、结果计算、账号权限、工程文件保存、完整拖拽停靠或桌面程序框架。
- 数值默认值和范围未确定，字段允许为空或作为文字草稿录入，不宣称工程数据合法。提交前只检查本演示所需的名称和选择。
- 自动化保留 CSS 125% 缩放检查；另外已在 macOS Chrome 原生 125% 缩放下检查主界面与三类弹窗，证据见 `../outputs/prototype-review-20261022/native-zoom-v0.2/`。Windows DPI 尚未验证。
- 生产构建中 Three.js 使入口包约 870kB（gzip 约 236kB），当前有包体积提醒，未进行真实大模型性能优化。

详见 [来源映射](docs/source-map.md)、[原型假设](docs/assumptions.md)、[图标清单](docs/icon-manifest.md)。项目规划与既有分析保留在上级目录；仓库包含原型源码、测试和项目文档；源码以外的本地证据未上传，本页指向 `../outputs/` 的路径仅在原工作目录中可用。
